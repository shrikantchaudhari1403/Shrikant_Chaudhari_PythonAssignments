8. What are instance and class variables in python ?
Ans: Instance variables and class variables are two types of variables used in Python classes. This is one of the most important OOP concepts
  eg 
        class Student:
            school= "vidya niketan"
            def __init__(self, name, age):
                self.name = name      # Instance Variable
                self.age = age        # Instance Variable

        s1 = Student("Rahul", 20)

        print(s1.name, s1.age)
        print(s2.name, s2.age)

output- Rahul 20
        Priya 22

9. Explain Instance method, static method and class method in python ?
Ans=>       
  1. An instance method works with instance variables. It takes self as its first parameter.
        First parameter is self.
        Can access and modify instance variables.
        Called using an object.
      class Student:

    def __init__(self, name, marks):
        self.name = name
        self.marks = marks

    def display(self):      # Instance Method
        print("Name:", self.name)
        print("Marks:", self.marks)

    s1 = Student("Rahul", 85)
    s1.display()

    Output

    Name: Rahul
    Marks: 85

    b. A class method works with class variables instead of instance variables.
       It uses the @classmethod decorator and receives cls (the class itself) as its first parameter
        
    Decorated with @classmethod.
    First parameter is cls.
    Accesses or modifies class variables.
    Can be called using either the class or an object.
    eg.
      class Student:

    school = "ABC School"

    @classmethod
    def show_school(cls):
        print("School:", cls.school)

        Student.show_school()

        Output

        School: ABC School

    c. 3. Static Method
       A static method does not use instance variables (self) or class variables (cls).
       It is just a regular function placed inside a class because it is logically related to that class.
       It uses the @staticmethod decorator.

       Decorated with @staticmethod.
       No self.
       No cls.
       Cannot directly access instance or class variables.

       eg:
       class Calculator:

    @staticmethod
    def add(a, b):
        return a + b

    print(Calculator.add(10, 20))

    Output

    30

10. Why we use @classmethod @staticmethod decotator to class ?
Ans-  The decorators @classmethod and @staticmethod tell Python how a method should behave. 
      Without these decorators, Python treats methods as instance methods by default
