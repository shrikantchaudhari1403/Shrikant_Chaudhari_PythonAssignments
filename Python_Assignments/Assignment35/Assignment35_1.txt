1. What machine learning ? and how is different from traditional rule based program ?

=> Machine Learning (ML) is a way of teaching computers to learn from data and experience instead of writing explicit rules for every situation
   Simple Example

Imagine you want to identify whether an email is spam.

Traditional Programming: You write hundreds of rules like "if email contains 'Win Money' then spam."
Machine Learning: You provide thousands of emails already labeled as spam or not spam. The computer learns the patterns on its own and can classify new emails accurately.

4. what is supervied machine learning ? why is labelled data is always mandatory in superviewed leanring ?   
Ans -> Supervised Machine Learning is a type of machine learning where the model learns from labeled data. It is called "supervised" because the model is trained using 
        examples where the correct answer is already known, like a teacher supervising a student.  

   Why is Labeled Data Mandatory?

       Because the model needs to know the correct answer during training.
       
5. explain why we can not train and test model using same dataset ? what problem will occurs if we do so ?
ans= > Because the model has already seen the training data. Testing it on the same data does not tell us how well it will perform on new, unseen data.
       The purpose of testing is to measure how well the model generalizes,  not how well it remembers.

9. what is the purpose of random_state=42 in test_train_split() what happed if we not provide it ?
Ans ->  When train_test_split() splits the dataset, it randomly selects which records go into the training set and which go into the test set.
     What Happens If We Don't Provide random_state?

  The dataset is still split randomly, but:

  Every execution can produce a different train/test split.
  Your model's accuracy may vary from run to run.
  Reproducing results becomes difficult.

10. what step by step internally happened when we use model.fit(x_train, y_train)?
=>    model.fit(X_train, y_train) trains a machine learning model using the
     training features and their corresponding labels. Internally,
      the model receives the data, initializes its parameters,
       makes predictions, compares those predictions with the actual labels using
        a loss function, updates its parameters to reduce the error, and repeats this
         process until it learns the relationship between the input features and the
          target values. After training, the model can make predictions on unseen data.
