Question4: Explain mean square root error with example ?
Answer->
Mean Squared Error (MSE) is the most common loss function for regression models.
It measures how far the model's predictions are from the actual values.

MSE = (1/n) * Σ(yᵢ - ŷᵢ)²

Example:

Actual values    = [10, 20, 30]
Predicted values = [12, 18, 25]

Step 1: Calculate errors

(10 - 12) = -2
(20 - 18) =  2
(30 - 25) =  5

Step 2: Square the errors

(-2)² = 4
( 2)² = 4
( 5)² = 25

Step 3: Calculate MSE

MSE = [4 + 4 + 25] / 3

MSE = 33 / 3

MSE = 11

Therefore, MSE = 11

Question5- what is binary cross entropy loss function ?
Answer ->
Binary Cross-Entropy is a loss function used for binary classification,
where there are only 2 possible classes.

Spam      → 1
Not Spam  → 0

Pass      → 1
Fail      → 0

Disease   → 1

Question7 - what is epoch in nural network training
Answer-> 1 Epoch = Entire training dataset processed once
An epoch is the complete journey through the training dataset.

Question8- Explain difference between epoch, batch size and iteration in nural network ?
Answer - eg- 
Total training data = 1,000 images
Batch size = 100
Epochs = 5

Batch size = how many training examples the network processes at one time
Iteration = one batch is processed and the model's weights are updated once.
Epoch = the entire training dataset has been processed once.

Question9 - what is cnn why it is popular in image processing ?
Answer->
CNN is a type of deep neural network specially designed to work with grid-like data, especially images.
It is very popular in image processing because CNN can automatically learn important visual features such as

Edges → Corners → Shapes → Textures → Objects

Answer- >
