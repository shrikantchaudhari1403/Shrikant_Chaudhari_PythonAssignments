Question1 - Explain waighted sum in neural network?
Ans- >
Weighted Sum in a Neural Network

A weighted sum is the first important calculation a neuron performs. It combines the input values with their corresponding weights to decide how strongly each input should influence the neuron.
The formula is:

$$ Z = (X_1W_1) + (X_2W_2) + (X_3W_3) + \cdots + b $$

where:

X₁, X₂, X₃ = input values
W₁, W₂, W₃ = weights
b = bias
Z = weighted sum (also called the neuron's pre-activation value)

Question4- What is learning rate ? what happends if it is too high or too low ?
Ans->
The learning rate is a hyperparameter that controls how much the neural network changes its weights and biases during each training step.

It is usually represented by α (alpha) or η (eta).

The weight-update formula is:

$$ \boxed{W_{new}=W_{old}-\alpha \times Gradient} $$

Where:

\(W_{old}\) = current weight
\(\alpha\) = learning rate
Gradient = direction and amount of error
\(W_{new}\) = updated weight

Question 8- Explain perceptron formula?
Ans-> 1. Weighted sum

First, the perceptron multiplies every input by its corresponding weight:

$$ z=x_1w_1+x_2w_2+x_3w_3+\cdots+x_nw_n+b $$

Or simply:

$$ \boxed{z=\sum_{i=1}^{n}x_iw_i+b} $$

Where:

\(x_i\) = input
\(w_i\) = weight
\(b\) = bias
\(z\) = weighted sum / net input
